Googleマップの設定

Googleマップ(航空写真・ストリート表示・ズーム)を使うには、Google Maps JavaScript API のAPIキーが必要です。 キーはこのPCのブラウザ内(localStorage)にだけ保存され、Googleの地図表示以外には使いません。
  1. Google Cloud Console でプロジェクトを作成し、請求先を設定
  2. Maps JavaScript API を有効化
  3. 「認証情報」でAPIキーを作成(HTTPリファラー制限の設定を推奨)
  4. 作成したキーを下に貼り付けて保存
キーを空にして保存すると、OpenStreetMap(キー不要)の地図に戻ります。
